# MJ-Fashion

MJ Fashion is a Django-based e-commerce website designed for showcasing and selling fashion and lifestyle products online.

## Features

- Home Page
- Product Search
- Shopping Cart
- Checkout Page
- Contact Form
- About Us Page
- Responsive Design
- Django Backend
- SQLite Database

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- Bootstrap
- JavaScript
- SQLite

## Installation

### Clone Repository

```bash
git clone https://github.com/jenishmalaviya981/MJ-Fashion.git
cd MJ-Fashion
```

### Run Migrations

```bash
python manage.py migrate
```

### Start Development Server

```bash
python manage.py runserver
```

Open:

http://127.0.0.1:8000/
